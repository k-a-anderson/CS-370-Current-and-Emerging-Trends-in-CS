# CS-370-Current-and-Emerging-Trends-in-CS
Pirate Intelligent Agent
Reinforcement Learning and Neural Networks Project
Project Overview

For this project, I worked on developing a pirate intelligent agent that uses deep Q-learning to navigate a maze and find treasure before a human player. The goal was to train the agent to learn the most efficient path to the treasure through trial and error, improving its performance over time.

Code Contribution

I was given starter code that included the environment setup, classes for managing the maze, and the basic structure for training the agent. My main task was to complete the Q-training algorithm inside the qtrain() function. I added logic for exploration and exploitation, implemented experience replay, handled memory management, and built the training loop to help the agent learn from past experiences. I also worked on refining the output so that it printed detailed training results, including epochs, losses, win rates, and completion checks.

Connecting Learning to Computer Science

Throughout this course, I learned how reinforcement learning connects to the larger field of computer science by demonstrating how systems can learn from experience to make better decisions without direct human input. Computer scientists build these types of intelligent systems to solve real-world problems—from optimizing routes in self-driving cars to automating decision-making in complex environments.

When approaching problems like this, I’ve learned to think logically and iteratively: break a large problem into smaller parts, test each component, and use debugging and analysis to refine the solution. Reinforcement learning projects especially require patience and experimentation since much of the process is about tuning parameters and analyzing outcomes over time.

Ethical Responsibilities

As a computer scientist, I have an ethical responsibility to make sure that AI systems are transparent, fair, and secure. That means ensuring models don’t make biased or harmful decisions, protecting user data, and designing systems that behave predictably and safely. It’s also important to think about how these technologies could impact users and society as a whole, especially as AI becomes more integrated into daily life.
